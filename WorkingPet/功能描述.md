# WorkingPet 功能描述

本文档描述 **代码实际实现** 的功能全景（而不是设想/规划中的功能）。截至本次整理（2026-07-08），入口文件为 `manei_manager.py`。

> ⚠️ `CLAUDE.md` 中提到的「心情系统（`self.mood`）」「主动说话（`_check_proactive_talk` / `generate_proactive_line`）」「`GIF_*` 常量」「`HoverPanel` / `_BTN_CFG`」「`_doubao_stream` 流式请求」目前**代码里都不存在**，是尚未落地的设计文档，不要当作现状参考。本文档只描述真实存在的代码。

## 1. 桌面悬浮宠物

- 无边框、置顶、可拖拽的 PyQt6 窗口（`DesktopPet`），显示一只 GIF 宠物 + 状态信息面板。
- 面板内容：当前时间、状态文案、今日已工作时长、距离下班还有多久、今日已赚金额。
- 右键菜单：设置参数 / 立即预览日报 / 退出。

## 2. GIF 状态机

由 `DesktopPet._get_state()` 按以下优先级判定，每 2 秒刷新一次（`self.timer`）：

| 状态 | 触发条件 | GIF |
|---|---|---|
| 下班 | 当前时间 ≥ `pm_end` | `xiaban.gif`，宠物放大 3 倍并居中显示 |
| 愤怒 | 连续操作（鼠标/键盘无中断）超过 `activity_angry_threshold` 秒 | `angry.gif` |
| 摸鱼 | 空闲时间超过 `idle_threshold_minutes` 分钟 | `SLEEPY.gif` |
| 听歌 | 检测到 `QQMusic.exe` 或 `cloudmusic.exe` 进程在运行（每 10 秒轮询一次） | `MUSIC.gif` |
| 默认 | 以上都不满足 | `manei.gif` |

活跃度判定基于 `pynput` 全局鼠标/键盘监听（`_start_input_listeners`），不区分具体按键内容。

## 3. 薪资实时计算

`_calc_earned()` 按 `月薪 / 21.75 天` 换算日薪，再按当前时间在 `[am_start, am_end]` `[pm_start, pm_end]` 两个工作时段内的已流逝秒数换算实时到手金额，显示在面板上。下班后面板变红并显示当日总收入。

## 4. 工作记录 & AI 对话入口

底部悬浮输入框（`ChatInput`）接收自由文本，提交后：

- **未配置 AI（无 `api_key`/`endpoint_id`）**：直接当作一条工作记录写入 `work_log.json`（`add_log`）。
- **已配置 AI**：调用豆包 `understand_intent()` 做意图识别，返回 JSON 判断以下四种意图之一：
  - `record` — 记录工作内容（`add_log`）
  - `generate_report` — 生成周报并复制到剪贴板，气泡上出现「打开钉钉」按钮
  - `open_dingtalk` — 直接启动钉钉
  - `chat` — 普通闲聊，AI 生成一句简短回复

所有 AI 调用在后台 `threading.Thread` 里执行，结果通过 `Bridge`（`QObject` + `pyqtSignal`）回传主线程更新气泡（`BubbleWidget`），不会阻塞 UI。

## 5. AI 周报生成

- `generate_weekly_report()` 汇总本周（周一到今天）`work_log.json` 中的记录，按固定格式（`WEEKLY_REPORT_FORMAT`）交给豆包生成周报正文，结果复制到系统剪贴板。
- 每周固定日期/时间（`report_config.remind_day` / `remind_time`，默认周五 11:00）会弹出气泡提醒「要生成本周周报吗」，输入框占位符相应变化。
- 可通过对话框直接说「生成周报」触发，走意图识别的 `generate_report` 分支。

## 6. AI 日报草稿 & 确认

- 每天下班前 10 分钟（`pm_end - 10min`）自动触发一次，或通过右键菜单「立即预览日报」手动触发。
- 生成草稿所用的原始数据（`generate_daily_summary()`）：
  1. **窗口标题记录**：工作时段内每 5 分钟采集一次前台窗口标题（过滤掉桌宠自身窗口）
  2. **截图视觉分析**：同样每 5 分钟一次（仅工作时段内），若配置了 AI，则截屏并调用豆包视觉模型生成一句话描述（`analyze_screenshot`），只保留文字描述，不保留截图本身
  3. **手动记录**：今天用户通过输入框记录的内容
  4. **后台上下文快照**（新接入）：`ContextCollector.get_context_snapshot()` 返回的中文输入/桌面上下文文字摘要，作为补充信息一并喂给 AI（音乐/歌词属于娱乐内容，不采集、不进日报）
- AI 归纳生成不超过 8 条工作条目的草稿，弹出 `DailyConfirmDialog` 可编辑文本框供用户核对/修改。
- 确认后用 `replace_today_logs()` **覆盖**（而非追加）当天的 `work_log.json` 记录；跳过则不保存，可后续手动补录。
- 未配置 AI 时，直接弹出空白框让用户手填。

## 7. 后台上下文采集（`context_collector.py`，随主程序启动）

`DesktopPet._start_background_collectors()` 在启动时实例化 `ContextCollector` 并调用 `start_all()`，默认只跑两路工作相关采集，任一采集器异常不影响主程序：

- **`InputCollector`**：每秒轮询系统剪贴板，识别新出现且含 ≥3 个汉字、长度 ≤200 的中文文本（输入法上屏内容常经过剪贴板），去重后按日保存到 `input_log.json`。
- **`ScreenshotCollector`**：仅当配置了 `api_key`/`endpoint_id` 时启用，启动 5 分钟后开始，此后每隔随机 15-30 分钟截一次全屏、调豆包视觉模型生成一句话描述保存到 `context_log.json`，**只存文字不存图**。
- **`MusicCollector`**（网易云当前播放歌名+歌词）：类定义保留，但 `start_all()` 不再启动它——音乐/歌词属于娱乐内容，不采集、不出现在日报里。

两路数据通过 `get_context_snapshot()` 汇总成一段文字（最近中文输入/桌面描述），供日报生成 prompt 使用（见第 6 节）。

## 8. 后台行为采集（`data_collector.py`，随主程序启动）

`_start_background_collectors()` 同时调用 `data_collector.start_all()`，启动 5 个独立守护线程，任一失败不影响其余：

- **聊天内容监听**（已禁用）：代码保留（`_start_chat_monitor`），但默认不启动。原因：`keyboard.hook_key suppress=True` 会全局拦截回车键，导致 CMD 等非聊天窗口的回车失效，影响正常使用。
- **屏幕 OCR**：启动 1 分钟后开始，每 3 分钟截屏一次，用 `EasyOCR`（中文+英文，CPU）识别屏幕文字，写入 `ocr_log.json`。
- **应用使用时长**：每 30 秒采集一次前台进程名与窗口标题，按天累计到 `raw_behavior.json` 的 `apps` 字段。
- **鼠标活跃度**：`pynput` 监听移动距离与点击次数，每 60 秒汇总一次写入 `raw_behavior.json` 的 `mouse` 字段（**不记录具体坐标轨迹**，只有聚合的移动距离和点击数）。
- **Chrome 浏览历史**：启动 5 分钟后开始，每 30 分钟复制一次 Chrome 的 `History` SQLite 文件到临时目录读取最近访问记录，写入 `browser_history.json`，用完删除临时文件。

> 这些采集目前只是**落盘**，尚未像 `context_collector` 那样被消费进 AI prompt——可以作为后续「更丰富的日报/周报」的数据来源。

## 9. 加班 / 下班提醒

- 到达 `pm_end` 时刻，`_enter_off_work_mode()` 把宠物放大 3 倍并移动到屏幕正中央，切到 `xiaban.gif`，面板变红显示「下班了！关电脑！回家！」。
- 回到工作时段（比如次日）会自动 `_exit_off_work_mode()` 恢复正常大小。

## 10. 钉钉一键启动

`_launch_dingtalk()`：优先用设置里配置的 `dingtalk_path` 启动，找不到则尝试直接调用 `DingTalk.exe`（依赖系统 PATH），都失败则气泡提示「找不到钉钉，请在设置里配置路径」。

## 11. 设置面板（`SettingsDialog`）

可配置项：上/下午上下班时间、月薪、无操作判定时间、宠物大小、连续操作触发愤怒的秒数、停止操作冷却时间、豆包 API Key、推理接入点 ID、周报提醒时间/星期、钉钉 exe 路径。保存后立即生效（部分参数会强制 `switch_gif(force=True)` 刷新显示），并写回 `config.json`。

## 12. 数据文件一览（均为本地运行期数据，已加入 `.gitignore`）

| 文件 | 产出模块 | 内容 |
|---|---|---|
| `config.json` | `manei_manager.py` | 用户配置 + API Key（**含敏感信息，不入库**） |
| `work_log.json` | `work_log.py` | 手动/AI日报记录，按日期分组 |
| `input_log.json` | `context_collector.InputCollector` | 今日中文剪贴板输入片段 |
| `context_log.json` | `context_collector.ScreenshotCollector` | 截图的文字描述 |
| `chat_input_log.json` | `data_collector` | 聊天窗口发送内容 |
| `ocr_log.json` | `data_collector` | 屏幕 OCR 文字 |
| `raw_behavior.json` | `data_collector` | 应用使用时长 + 鼠标活跃度 |
| `browser_history.json` | `data_collector` | Chrome 浏览历史 |
