# 动画资源约定

把同一语义状态的 GIF 放进对应目录，程序会在状态变化时随机选择一个，且避免连续重复；目录为空时会继续使用旧版 GIF，不会影响运行。

```text
assets/animations/
  focus/       # 专注工作，例如打字、阅读、思考
  idle/        # 休息/摸鱼，例如打盹、喝水
  intense/     # 连续高强度操作
  music/       # 听歌
  off_work/    # 下班
```

建议每个目录先准备 2–4 个 GIF，保持相同的画布尺寸、宠物位置和透明背景。短事件动画（升级、购买、日报确认）后续可放到 `event/` 并在事件发生时单次播放。
